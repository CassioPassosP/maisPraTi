Projetos

To do List

O Projeto React Lista de Tarefas é uma aplicação desenvolvida em React utilizando Vite, criada para treinar conceitos fundamentais de componentes, estados e propriedades. O sistema permite cadastrar e gerenciar tarefas de forma simples e intuitiva, com uma interface responsiva e limpa. Além de aplicar boas práticas de organização de código, o projeto também simula persistência de dados, servindo como base para evolução futura com recursos mais avançados. Ver mais

Número da Sorte

“Número da Sorte” é um jogo educativo simples desenvolvido como exercício nos cursos de Lógica de Programação e Git/GitHub. Com HTML, CSS e JavaScript, o projeto explora listas, funções e controle de fluxo para gerar e adivinhar um número secreto de forma interativa, oferecendo ao usuário feedback imediato.
